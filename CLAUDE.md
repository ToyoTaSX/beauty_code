# CLAUDE.md

Лендинг парикмахерской. Онлайн-записи и форм нет. Главная кнопка
«Позвонить» (`tel:`), вторая - «Написать в Telegram»: ссылка `https://t.me/<username>`
открывает личный чат с мастером.

Проект - только статический сайт на GitHub Pages. Бэкенда, бота, базы данных
и секретов нет.

## Стандарт - главный документ

**Перед любой вёрсткой прочитай [docs/STANDARD.md](docs/STANDARD.md).** Там
экраны, сетка, типографика, токены цветов, список компонентов, правила прайса
и чек-лист приёмки. Этот файл его не повторяет, а описывает техническую часть.

- Страница собирается только из компонентов раздела 5 стандарта. Нужен новый -
  сначала предложи дописать его в стандарт.
- Цвета только через токены, отступы только из шкалы, два шрифта.
- Ошибку, найденную при проверке, записывай правилом в раздел 8 стандарта.
- Шаг закрыт, только когда пройден чек-лист раздела 7.

## Связь вместо формы

Форма обратного звонка и бот отложены. Вместо них - кнопка «Написать в
Telegram».

- Кнопки: «Позвонить» - заливка `--accent`, главное действие; «Написать в
  Telegram» - контурная, вторая. Рядом номер телефона текстом.
- Ссылка: `https://t.me/<username>` с `target="_blank" rel="noopener"`. Не
  `tg://`: на десктопе без установленного Telegram она не откроется.
- Контакт берётся из данных, не из разметки:
  - `site.json` -> `telegram` - общий контакт (пока один аккаунт на всех);
  - `masters.json` -> `telegram` у мастера - необязательное поле; если его нет,
    кнопка «Написать мастеру» ведёт на общий контакт.
  Сменить аккаунт = поправить одно поле в JSON.
- Предзаполненный текст сообщения (`?text=`) для личных чатов работает не во
  всех клиентах Telegram, на него не полагаемся.
- Иконка Telegram - инлайн-SVG в цвете текста кнопки, не картинкой.

## Стек

| Что | Выбор | Почему |
|---|---|---|
| Генератор | **Astro 7**, статическая сборка (`output: 'static'`) | GitHub Pages отдаёт только статику; компоненты без JS в браузере по умолчанию, данные из JSON на этапе сборки |
| Язык | TypeScript (strict) | |
| Стили | обычный CSS: `tokens.css` с переменными из стандарта + scoped `<style>` в компонентах | без Tailwind: токены и шкала отступов уже заданы стандартом |
| JS в браузере | ванильный TS в `<script>` компонентов, без фреймворков | шапка, лента, раскрывашки, лайтбокс - мелочи, React не нужен |
| Картинки | `astro:assets` (`<Picture>`) - AVIF + WebP, `srcset`, `loading="lazy"` кроме первого экрана | требование стандарта и Lighthouse |
| Шрифты | `@fontsource/prata` и `@fontsource-variable/manrope` - woff2 из npm, latin + cyrillic, `font-display: swap`, preload Prata cyrillic | без Google Fonts CDN |
| Данные | `src/data/prices.json`, `masters.json`, `gallery.json`, `site.json` (телефон, telegram, адрес, часы, ссылки) | один источник правды, в разметке значений нет |
| Проверка данных | схемы Zod в `src/lib/data.ts` | сборка падает, если в прайсе нет цены или у контакта неверный формат |
| Карта | виджет 2ГИС, подгружается через `IntersectionObserver` | карта только при прокрутке до неё |
| Хостинг | **GitHub Pages**, деплой через GitHub Actions (`withastro/action`) | |

## Структура

```
/
├─ CLAUDE.md
├─ docs/STANDARD.md
├─ astro.config.mjs        site, base для GitHub Pages
├─ public/fonts/           woff2
├─ src/
│  ├─ components/          по одному файлу на компонент из стандарта
│  ├─ data/                prices.json, masters.json, gallery.json, site.json
│  ├─ images/              исходники фото: works/, masters/ (оптимизирует astro:assets)
│  ├─ layouts/Base.astro   head, шрифты, стили
│  ├─ lib/data.ts          схемы данных, formatPrice, ссылки tel: и t.me
│  ├─ styles/              tokens.css, base.css, fonts.css
│  └─ pages/index.astro
└─ .github/workflows/deploy.yml сборка и деплой на Pages
```

## Команды

Node.js 24 LTS, npm. TypeScript 6 (`@astrojs/check` пока не поддерживает 7).

```bash
npm install
npm run dev        # локально, http://localhost:4321
npm run build      # astro check + статическая сборка в dist
npm run preview    # просмотр сборки
npm run check      # astro check: типы и схемы данных
```

## GitHub Pages - на что смотреть

- Репозиторий: https://github.com/ToyoTaSX/beauty_code, сайт:
  https://toyotasx.github.io/beauty_code/. Деплой - каждый пуш в `main`.

- Сайт на `https://<user>.github.io/<repo>/`: в `astro.config.mjs` задать
  `site` и `base`, все ссылки и пути к ассетам строить через
  `import.meta.env.BASE_URL`. Когда появится свой домен - `base: '/'` и файл
  `public/CNAME`.
- Проверка по чек-листу - по публичной ссылке Pages, не локально.

## Данные и фото

- Пока данных салона нет, в JSON стоит `"example": true` и тексты с пометкой
  «Пример»; на странице показывается бейдж «Пример». С настоящими данными
  флаг убираем.
- Фото кладём в `src/images/works/` и `src/images/masters/`, в JSON пишем путь
  относительно `src/images` (`"works/01.jpg"`). Пустая строка = заглушка
  «Фото скоро». Работы и мастера - кадрируем в 4:5.

## Правила работы

- Мобильная версия первая: верстаем на 390 px, потом 720, 1080, 1440.
- После изменений вёрстки смотри страницу в браузере на 390 / 720 / 1440 px,
  проверь консоль и отсутствие горизонтальной прокрутки.
- Цены и услуги правятся только в `src/data/prices.json`, контакты - только в
  `site.json` и `masters.json`, не в разметке.
- Никаких выдуманных фактов, имён, отзывов и цифр - см. раздел 6 стандарта.
- В текстах сайта только дефис, длинное тире не используем.
- Новые зависимости добавляем только с объяснением зачем; каждый килобайт JS
  бьёт по Lighthouse.

## Отложено

- Форма «Перезвоните мне» с уведомлением менеджеру через Telegram-бота.
  Когда вернёмся: сервер на зарубежном VPS (он уже есть) - Node.js + Hono +
  grammY, Caddy для HTTPS, поддомен `api.<домен>`. Учесть доступность IP из
  РФ и 152-ФЗ (трансграничная передача ПДн).
