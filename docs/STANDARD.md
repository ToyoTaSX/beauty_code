# STANDARD.md - образец стандарта страницы

---

## 1. Экраны

| Ширина | Что это | Правило |
|---|---|---|
| 390 px | телефон, основной экран | проверяем первым, 80% трафика здесь |
| 720 px | планшет | с него начинаются 2-4 колонки |
| 1080 px | десктоп | полное меню в шапке |
| 1440 px | широкий десктоп | контент не шире 1280 px |

- Горизонтальной прокрутки страницы нет ни на одной ширине.
- Ленты карточек прокручиваются внутри своего блока, а не всей страницей.
- Мобильная версия первична: сначала верстаем 390, потом расширяем.

## 2. Сетка и отступы

Настроение: тёплый минимализм. Много воздуха, крупные фото работ, мало
украшений. Главное на странице - фотографии стрижек, остальное им не мешает.

- Контейнер: `max-width: 1200px`, поля 20 px на телефоне, 40 px от 720 px.
- Секция: отступ 56 px сверху и снизу на телефоне, 96 px от 720 px.
- Шаг отступов внутри блоков: 4, 8, 12, 16, 24, 32, 48 px. Других значений нет.
- Сетка: 4 колонки на телефоне, 8 от 720 px, 12 от 1080 px, зазор 16 / 24 px.
- Пропорции фото: работы и мастера 4:5 (портрет), интерьер 3:2, первый
  экран 4:5: на телефоне фото под текстом, от 720 px - справа от текста.
- Скругления: 6 px карточки и фото, кнопки и поля полностью круглые
  (`border-radius: 999px`). Других скруглений нет.
- Тени не используем. Карточку отделяют фон `--surface` и рамка 1 px `--line`.

## 3. Типографика

| Роль | Шрифт | Телефон | От 720 px |
|---|---|---|---|
| H1 | антиква (Prata) 400 | 40 px | 64 px |
| H2 | антиква (Prata) 400 | 30 px | 44 px |
| H3 (услуга, имя мастера) | гротеск (Manrope) 600 | 19 px | 21 px |
| Текст | гротеск (Manrope) 400 | 16 px | 17 px |
| Надзаголовок | гротеск 600, капс, разрядка 0.12em | 12 px | 13 px |
| Цена | гротеск 600, `font-variant-numeric: tabular-nums` | 17 px | 18 px |
| Подписи | гротеск 400 | 13-14 px | 13-14 px |

- Два шрифта на весь сайт. Третий не добавляем.
- У Prata одно начертание 400. Жирную антикву не имитируем:
  `font-synthesis: none`. Слово в заголовке выделяем только цветом
  `--accent`, без курсива.
- Шрифты лежат локально в woff2 (подмножества latin + cyrillic) с
  `font-display: swap`: CDN шрифтов бывает недоступен, и страница висит.
- Межстрочный интервал текста 1.6, заголовков 1.1-1.15.
- Длина строки текста не больше 65 знаков.

## 4. Цвета (токены)

Все цвета только через переменные. Смена стиля сайта = замена этого блока.
Палитра: кремовый фон, тёмный «эспрессо» для текста, терракотовый акцент.

```css
--bg:          #f7f2ec;  /* фон страницы, тёплый крем */
--bg-alt:      #eee5da;  /* фон чередующихся секций */
--surface:     #fffcf8;  /* карточки */
--ink:         #2b211c;  /* основной текст, эспрессо */
--muted:       #6b5d55;  /* второстепенный текст */
--line:        #e2d5c8;  /* рамки и разделители */
--accent:      #9c4a2a;  /* главная кнопка, ссылки, терракота */
--accent-ink:  #fff8f2;  /* текст на акценте */
--accent-soft: #f4e2d7;  /* бейджи, подложки */
--deep:        #2b211c;  /* тёмные секции, подвал */
--deep-ink:    #f3ebe2;  /* текст на тёмном */
--deep-muted:  #bfae9f;  /* второстепенный текст на тёмном */
--deep-accent: #e08b62;  /* ссылки и акценты на тёмном */
```

Проверенный контраст (норма не ниже 4.5:1):

| Пара | Контраст |
|---|---|
| `--ink` на `--bg` / `--bg-alt` | 14.1 / 12.6 |
| `--muted` на `--bg` / `--bg-alt` / `--surface` | 5.7 / 5.1 / 6.2 |
| `--accent-ink` на `--accent` | 5.8 |
| `--accent` на `--bg` / `--accent-soft` | 5.5 / 4.9 |
| `--deep-ink` / `--deep-muted` / `--deep-accent` на `--deep` | 13.3 / 7.3 / 6.0 |

- `--line` только для рамок, текстом им не пишем.
- `--accent` не больше одной заливки на экран: главная кнопка. Остальное -
  ссылки и мелкие акценты.
- Поверх фото текст кладём только на затемнение
  `linear-gradient(transparent, rgb(43 33 28 / .7))`.

## 5. Компоненты

Страницу собираем только из них. Нужен новый - сначала добавьте его сюда.

| Компонент | Что внутри | Поведение |
|---|---|---|
| Шапка | лого, меню | при прокрутке сжимается и прилипает |
| Первый экран | H1, подзаголовок, фото, адрес и часы работы, кнопки связи | фото не грузит страницу дольше 2 с |
| Заголовок секции | надзаголовок, H2, подзаголовок, стрелки ленты | стрелки только от 720 px |
| Лента (rail) | горизонтальный ряд карточек | свайп на телефоне, стрелки на десктопе |
| Прайс | ряд категорий-чипов, группы услуг, строка «услуга - цена от», пометка о цене | см. правила прайса ниже |
| Карточка мастера | фото 4:5, имя, специализация, кнопка «Написать мастеру» | кнопка открывает Telegram мастера, если его нет - общий Telegram салона |
| Галерея работ | лента фото 4:5 | тап открывает фото крупно, листается свайпом и стрелками |
| Раскрывашка | вопрос или заголовок, скрытый текст | открыта одна за раз |
| Кнопки связи | «Позвонить» (заливка `--accent`), «Написать в Telegram» (контурная), номер телефона текстом | на телефоне кнопки друг под другом во всю ширину, от 720 px в ряд |
| Конверсионный блок | фон-фото, заголовок, кнопки связи | 2-3 раза за страницу |
| Отзывы | только настоящие: виджет или ссылка на Яндекс Карты / 2ГИС | своих текстов отзывов не пишем |
| Контакты | адрес, часы работы, карта 2гис, как пройти, телефон | карта грузится, только когда до неё долистали |
| Подвал | 4 колонки ссылок, контакты | колонки складываются в 1 на телефоне |

### Правила прайса

- На сайте полный прайс. Все цены с «от»: «от 1 500 ₽», неразрывный пробел
  до и после числа и перед ₽.
- Прайс хранится в одном файле данных (JSON), страница строится из него.
  Цены руками в вёрстке не правим.
- Группы - по категориям салона (например: женские стрижки, мужские
  стрижки, детские, окрашивание, уход, укладки). Точный список берём у
  заказчика.
- Строка: название услуги слева, цена справа, между ними пунктир или
  свободное место. Под названием может быть одна строка пояснения
  `--muted` (длина волос, время). Цены выровнены по правому краю,
  `tabular-nums`.
- Над прайсом ряд чипов с категориями: тап прокручивает к группе. На
  телефоне ряд прокручивается вбок и прилипает под шапкой.
- На телефоне группы - раскрывашки, первая открыта. От 720 px все группы
  открыты, в 2 колонки от 1080 px.
- Под прайсом пометка, от чего зависит итоговая цена, и кнопки связи.
  Текст пометки согласовываем с салоном.
- Строка услуги не ссылка и не кнопка: тап по ней ничего не делает.

### Запись

- Онлайн-записи и форм на сайте нет. Записывают по телефону или в Telegram.
- Главное действие на всей странице - «Позвонить» (`tel:`), оно заливается
  `--accent`. «Написать в Telegram» - вторая кнопка, контурная.
- Telegram открываем ссылкой `https://t.me/<username>` в новой вкладке, не
  `tg://`: она работает и без установленного приложения.
- Контакты (телефон, общий Telegram, Telegram мастеров) хранятся в файлах
  данных, в вёрстке их руками не пишем.
- Номер телефона написан текстом рядом с кнопкой, чтобы его можно было
  набрать вручную с десктопа.

## 6. Контент

- Никаких выдуманных фактов, цифр, наград, имён. Нет данных - подпись роли
  или пометка «Пример».
- Кнопка называет действие: «Записаться на консультацию», а не «Отправить».
- Длинное тире не используем, только дефис.

## 7. Критерии проверки каждого шага

Шаг не закрыт, пока все пункты не отмечены.

- [ ] Открыл по публичной ссылке, не локально.
- [ ] 390, 720, 1440 px: нет горизонтальной прокрутки, текст не обрезан.
- [ ] Телефон в руке: кнопки нажимаются пальцем, минимум 44 px.
- [ ] Главная кнопка ведёт к действию: «Позвонить» набирает номер,
      «Написать в Telegram» открывает нужный чат.
- [ ] Консоль браузера без ошибок.
- [ ] Lighthouse mobile: Performance и Accessibility от 90.
- [ ] Все цвета из токенов, все блоки из списка компонентов.
- [ ] Прайс: все цены с «от», совпадают с файлом данных и прайсом салона,
      неразрывные пробелы на месте.
- [ ] С телефона «Позвонить» набирает номер; «Написать мастеру» открывает
      Telegram этого мастера (или общий, если своего нет).
- [ ] Фото в WebP или AVIF, работы и мастера 4:5, карта грузится только
      при прокрутке до неё.
- [ ] Заголовки на кириллице набраны Prata, а не запасным шрифтом,
      поддельного жирного нет.

## 8. Журнал правил

Сюда дописываются правила, найденные на ошибках агента.

- Градиент `linear-gradient(transparent, rgb(43 33 28 / .7))` затемняет только
  низ фото. Если текст стоит и сверху (конверсионный блок), под градиент
  добавляем ровный слой `rgb(43 33 28 / .6)` на всё фото.
- Фото у салона вертикальные, сняты на телефон (~1150 px по ширине). Полоса
  16:9 на всю ширину десктопа требует от 2400 px и с ними выглядит мыльной.
  Ширина фото на странице в CSS-пикселях x2 не должна превышать ширину
  исходника.
- Блок мастеров не показываем, пока нет их фото: карточки с заглушками
  выглядят пусто. Данные лежат в `masters.json`, компонент `MasterCard`.
